## Description

This is a mystery game where users solve the mystery of a stolen diamond necklace by finding out who is the thief.

An example would be:
User input:
- the culprit: Brielle

expect output:
- Brielle is innocent, the thief is still out there.

User input:
- the culprit: Merilin

expect output:
- Merilin is the thief, you solved the mystery.
