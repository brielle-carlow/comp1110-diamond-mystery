## Description

This is a mystery game where users solve the mystery of a stolen diamond necklace by finding out who is the thief.

An example would be:
User input:
- the culprit: Brielle

expect output:
- CASE UNSOLVED. Sorry! That is not the correct suspect. You accused the wrong person.

User input:
- the culprit: Merilin

expect output:
- Congratulations! You solved the mystery!
